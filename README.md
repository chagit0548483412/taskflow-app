# TaskFlow MVP

TaskFlow is a project management tool. This MVP focuses on task management, authentication, and a responsive Kanban board.

## Getting Started
1. `cd backend && npm install && npm run start:dev`
2. `cd ../web && npm install && npm run dev`

## Infrastructure Note
For the MVP, we use local PostgreSQL and SQLite for development. Terraform/EKS configuration is documented in the design specs but not included in this local runner.
